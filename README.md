## Code availability and limitations

This repository contains scripts and related files used during the preparation of my B.Sc. thesis. The materials are provided for transparency and documentation purposes.

The repository should not be treated as a fully automated replication package. Some scripts may depend on local file paths, intermediate data files, package versions, or external datasets that are not included here. Therefore, no guarantee is made that all scripts will run without modification in a different computing environment.

Where possible, the repository documents the main data-processing steps, model specifications, and output-generating scripts used in the thesis.
